# 04 - Modulos do Sistema

1. Dashboard (Home) - Resumo do dia, totais, alertas, carregamentos em andamento
2. Pedidos - Criar pedido por posto, itens, status tracking
3. Carregamentos - Vincular pedido, motorista/cavalo/tanque, status, baixa de estoque
4. Estoque - Saldo por tanque, movimentacoes, snapshot diario, historico
5. Emprestimos/Devolucoes - Controle entre postos, status, datas
6. Cotacoes - Registrar preco (modal confirmacao), historico, comparacao (melhor preco destacado)
7. Cadastros - Postos, Combustiveis, Fornecedores, Motoristas, Cavalos, Tanques
8. Parametros - Credenciais criptografadas + configs gerais
9. Usuarios - Gestao de usuarios e perfis (admin only)
10. Historico - Historico de carregamentos, pedidos, movimentacoes com filtros
