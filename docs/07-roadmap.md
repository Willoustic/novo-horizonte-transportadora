# 07 - Roadmap e Fases

## Fase 1 - MVP (7 dias) EM ANDAMENTO

- Cadastros, Auth, Pedidos, Carregamentos, Estoque, Emprestimos
- Cotacoes (registro + comparacao), Dashboard, Parametros
- Deploy Vercel + Supabase (gratuito)

## Fase 2 - Automacao de Precos (+1-2 semanas)

- Scraping do portal Vibra (2FA por email)
- Parser de WhatsApp (cola-e-aprova -> automatico)
- Relatorios avancados / projecao de necessidade
- Importacao de planilhas antigas

## Fase 3 - Evolucao (+futuro)

- PWA para motoristas
- Integracao fiscal (NF-e / SEFAZ)
- App mobile nativo
- Migracao para hospedagem paga
